# Python: le schede

Riferimento rapido al linguaggio, pensato per stare aperto accanto agli esercizi. Non è un corso
completo: copre le parti che un data engineer usa ogni giorno, con esempi da provare.

## Come usarle

- Non leggerle tutte in una volta. Il README di ogni esercizio dice quali servono prima.
- Ogni scheda finisce con **Prova tu**: tre cose da fare nel REPL (`uv run python`) o in
  `playground/prove.py`. Falle davvero: leggere Python senza scriverlo non funziona.
- Se un metodo non è in una scheda, la scheda 01 spiega come trovarlo da solo. È la scheda
  più importante: le altre sono un riassunto di quello che potresti scoprire con quei
  strumenti.
